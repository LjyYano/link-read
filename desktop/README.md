# LinkRead for macOS

本仓库独立维护收费桌面产品，项目自有代码采用根目录[专有源码许可](../LICENSE)。源码可用于个人非商业评估和已授权开发；正式使用与再分发按相应商业授权执行。支付、激活与订阅服务尚未实现。

应用自带 `../src/linkread_desktop/` 后端，不依赖免费的 `link-read` CLI 仓库或其已安装包。来源与历史许可见[授权说明](../docs/licensing.md)。

粘贴 YouTube、B 站视频或 Apple Podcasts 单集的 HTTPS 链接，或粘贴、选择、拖入 SRT / VTT / JSON 字幕文件，再点击「生成文章」。复制的带时间戳字幕内容也可以直接粘贴，校验后显示为文件。所有来源均使用设置中选定的 AI 工具，执行摘要、全文标点校对、章节、关键词、导图及阅读页生成。首页展示最近文章和实时任务进度；生成中仍可继续输入链接或导入文件，后续任务按 FIFO 顺序排队，当前任务结束（成功、失败或取消）后再执行下一项。取得来源信息后显示真实标题、来源、时长和可用的封面，播客不必等 ASR 完成。

点击文章进入阅读页，顶部水平标签与离线 HTML 一致。宽窗口在左侧显示章节目录，窄窗口在正文上方展开目录。顶部支持在浏览器打开、导出 HTML / Markdown、打印 / 保存 PDF，以及在 Finder 显示归档。菜单支持方向键和 Escape，⌘O 导入字幕，⌘, 打开设置，⌘K 快速打开文章。Windows/Linux 对应使用 Ctrl。

- 「设置 → 语言」可分别选择界面语言和生成网页语言。界面默认跟随系统首选语言，中文系统使用简体中文，其余使用英文。随 App 运行的命令行进度和错误跟随界面语言。
- 网页默认使用原字幕语言。选择简体中文或 English 后，新的任务会按所选语言生成阅读页和 AI 整理内容。正文直接显示最终生成的内容。字幕索引和时间戳来自已保存的原字幕，发布者简介及原文引用保留来源措辞。排队与重试沿用任务提交时的网页语言。

- 默认使用本机已登录的 Codex CLI。可在「设置」填写可执行文件的绝对路径，留空时会检查 `PATH`、Homebrew 和常见的用户目录。
- Claude Code 沿用核心的 bare API 模式，从启动环境读取 `ANTHROPIC_API_KEY`。从 Finder 打开的 App 通常读不到 shell 配置文件里设置的环境变量。
- 视频需要有可获取的字幕。字幕和 AI 请求失败时会显示错误。可以取消正在生成的任务，也可以在尚未启动前取消排队任务；失败和取消后均可重试，已完整保存的阶段产物会复用。已完成的文章只显示「已完成」与日期，不再保留 100% 进度条。未完成任务会保存到本地；重启后等待点击「继续」，不会自动启动模型或语音识别。
- 应用资料库默认位于 `~/Library/Application Support/com.yano.linkread/library`。归档仍使用兼容的字幕和笔记格式，迁移不修改已有资料。也可以在启动 App 时通过 `LINKREAD_DESKTOP_LIBRARY` 指定已有资料库的绝对路径。应用只展示已经生成 `article.html` 的条目。

## 开发

需要 macOS、Xcode 命令行工具、Rust 1.90+、Node.js 22.12+ 和 Python 3.11+。在仓库根目录运行以下命令。

```sh
if [ ! -x .venv/bin/python ]; then
  python3 -m venv .venv
fi
.venv/bin/python -m pip install -e '.[youtube,test]'
npm ci --prefix desktop
sh desktop/dev.sh
```

在仓库根目录运行 `sh desktop/dev.sh` 启动和验证桌面应用。脚本根据自身位置定位仓库，准备 Rust stable，并默认使用仓库的 `.venv/bin/python`。可以通过 `LINKREAD_PYTHON` 指定解释器的绝对路径。

## 构建本机架构的 App

在仓库根目录运行以下命令。

```sh
.venv/bin/python -m pip install 'pyinstaller>=6,<7'
cd desktop
npm run app
```

产物位于 `src-tauri/target/release/bundle/macos/LinkRead.app`。App 带有 Python 运行时、独立的 LinkRead Desktop 后端、`yt-dlp` 和离线阅读页资源，运行机器需安装并配置所选 AI 工具。构建默认使用临时签名供本机测试，公开分发需要 Developer ID 签名及 Apple 公证。

正式发行还需针对实际构建环境整理完整依赖清单、版权与许可文本，并履行适用的源码提供义务。PyInstaller 的商业打包例外不能替代其他依赖授权；yt-dlp 的 Python 包与官方预编译二进制许可也不能混用。当前 FFmpeg 由用户安装，没有随 App 分发。详见[第三方声明](../THIRD_PARTY_NOTICES.md)。本地构建成功不代表这些发行检查已经完成。

## 进程接口

Rust 启动 Python 核心，并使用 Tauri IPC 通道传递标准输出中的 JSON Lines。每个 `progress` 对象有 `stage` 和 `message`，AI 分批阶段也会返回 `completed` 与 `total`；播客 `metadata_done` 和字幕保存事件均可附带经过来源白名单校验的 `metadata`。进度百分比根据已完成的提取阶段及 AI 批次估算，执行期间保持单调递增且最多显示 99%；成功后移除进度条，只显示「已完成」。模型响应时长不可预测，因此百分比不代表剩余时间。成功时发送 `completed` 事件和文章元数据，失败时发送 `error` 事件。前端 FIFO 队列保证同一时间只调用一个 `generate`；IPC 生成和取消使用同一个唯一 `requestId`，取消会终止该任务的 sidecar 进程组，任务完成的 Promise settle 后才会启动下一项。书架与 Markdown 导出通过独立请求读取。阅读完成和收藏通过独立 patch 请求保存；同一单集的写入串行执行，旧书架响应不能覆盖刚保存的状态。

## 直接 API Provider（无需安装 Codex / Claude Code）

在「设置 → AI 生成」选择「自定义 API」并填写：

- **API 地址**：兼容 OpenAI Chat Completions 的 API 根地址，例如 `https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1`，或者本机 `http://127.0.0.1:8000/v1`。
- **模型**：供应商提供的实际模型 ID，例如 `deepseek-chat`（以服务商当前文档为准）。
- **API 密钥**：只在首次或更换密钥时输入。保存时写入 **应用数据目录中的私有文件（权限 0600）**，不会放进 `localStorage`、项目 JSON、日志或命令行参数。默认用固定长度圆点和「已保存」表示；点击「更换」编辑，在更多菜单中显示或删除。

设置页分为「AI 生成」与「无字幕时转写」两组，说明收进问号，高级参数默认折叠。底部「保存设置」固定可见：有改动时启用，保存成功后留在本页并显示「设置已保存」。返回、Escape、通过快速打开或任务中心跳转阅读时会检查未保存内容。保存前完成全部相关字段校验，后续写入失败会恢复已更改的密钥；恢复失败会明确提示并重新读取实际凭据，不将未保存配置应用到生成任务。

要求服务商提供符合 `/chat/completions` 格式的 API，并能按照 JSON Schema 返回结构化的 JSON 对象。不同厂商支持程度不同，模型不兼容时会给出可读错误。设置页增加显示/隐藏 Token 的眼睛按钮，以及使用当前填写的配置进行一次小请求的「测试连接」。Token 通过进程环境变量仅传给当前生成任务的 Python sidecar；请求设置禁止跨域重定向，以避免泄漏 Bearer Token。非本机远程 API 必须使用 HTTPS。

## 重复视频、任务和删除

- 重复提交同一个 YouTube 视频（短链接、watch 等）或 B 站视频（含分 P）时，会先检查正在执行的队列和已有资料库，并要求确认是否重新生成并替换。取消确认不会清空输入框。
- 用户确认替换后，**在按来源和模型配置隔离的工作目录中生成新文章**，只有成功后才发布替换；失败或取消保留原文章及通过校验的批次。再次处理同一来源和配置时复用成功批次，切换模型、服务地址或工具路径不会混用。旧文章的归档 ID 保持不变。
- 失败或已取消的任务列表提供「重试」与「删除」。此处删除仅移除界面任务记录，不删除可复用的阶段缓存。
- 已完成文章的 `…` 菜单提供「删除文章」，确认后会永久删除该篇文章本地归档文件夹（包括原始字幕、AI 笔记与 HTML），而不是只隐藏列表项。生成任务正在运行时为保护磁盘数据，不支持删除已完成文章。
- 未完成队列保存到 App 数据目录的私有任务记录；重启后，原来排队、运行或取消中的任务显示为等待继续，失败和取消记录保持原状态。点击继续会重新检查当前设置、来源和重复文章；替换已有文章仍需确认。记录中不保存 API Token，最多保留 50 个未完成任务，达到上限时提示清理，不丢弃旧任务。

当前自定义 API 配置是**单份配置**，不包含 API 流式输出、工具调用或额外兼容性探测。调用第三方服务会将提供的字幕内容发送给该服务商，请自行确认内容使用权、模型资费和隐私条款。

### Token 存储与迁移

新版本 API Token 保存在当前用户的 LinkRead App Data 目录中的 `api-token` 文件，权限为 `0600`，不会写入 `localStorage` 或项目仓库。此文件**不是加密存储**，本机同一用户或有该用户权限的进程可能读取。升级时，如果旧版本曾将 Token 保存到 macOS Keychain，新版本会在首次读取时迁移到私有文件，并尝试删除旧 Keychain 项；后续新 Token 不再保存在 Keychain。可在密钥行更多菜单中选择「删除已保存密钥…」；这是二次确认后立即生效的操作，确认提示会说明取消设置不会恢复已删除密钥。

「测试连接」会向当前 API 地址的 `/chat/completions` 发送一次短请求验证模型与密钥（可能产生极少量 API 费用），成功后显示绿点「已连接」，失败后显示不包含密钥和字幕的错误。**已找到 Codex / Claude CLI 的绿点只代表找到了可执行文件，不代表登录认证已通过。**

## 首页与进度反馈

- 首页链接输入框默认单行，灰色提示引导粘贴链接。悬停或键盘聚焦导入图标时显示「导入字幕」，拖入文件时提示松开，问号可查看支持的来源与格式。空输入时「生成文章」保持禁用。新链接缺少 AI 配置时，点击「配置 AI 工具」可直达相关设置，返回首页后保留输入。
- 首页、书架和阅读页都可通过标题栏的任务图标打开任务中心。折叠的「最近完成」保留最多八篇仍在书架中的成功记录，重启后也能从这里打开。首页显示当前处理卡及排队、待查看提示，Escape 可关闭抽屉并回到当前页面。
- 新失败与中断记录保留未查看提醒，只有实际滚动到可见区域后才记为已查看。「清理已查看记录」需确认并先保存任务日志，仅读取/移除已结束的记录，不删除字幕、阶段缓存或书架文章，不影响运行与排队任务。
- 首页「继续阅读」从最近打开、尚未手动标记完成且仍在书架中的文章选取一条。卡片显示文章标题，点击后恢复保存的段落、Tab 和导图状态。
- 最近文章按完成顺序显示最多 6 篇，并包含上方的续读文章。如果续读文章排在六篇之外，它会占用最后一个卡片位置。视频封面铺满 16:9 媒体区，播客方形封面完整显示，两侧延展封面色彩。书架保留固定媒体列、搜索与紧凑列表。生成任务与已完成文章分开显示。
- 卡片优先展示已知节目名或作者，缺失时回退平台；「音频约 42 分钟」「视频约 29 分钟」表示原媒体时长。日期显示「昨天更新」或短月日，跨年显示年份，悬停可看完整更新时间。
- 任务显示真实阶段、已完成批次、累计耗时；运行时进度条带移动高亮与条纹，等待动画不会改变完成比例，非运行状态停止动画。遵循系统「减少动态效果」偏好。超过 20 秒没有新事件时，显示等待响应的时长，不编造百分比或剩余时间。
- 主卡片仅显示已完成批次数，不再将「第 3/3 批已调度」误读为「完成 3/3」；原始调度事件仍在处理详情中保留。
- 「查看处理详情」展示并行的正文校对、摘要与导图整理状态，以及最近 12 条实际处理事件。后到达的并行消息不会被丢弃。
- 详情状态以整个任务的终态为准：失败、取消后不再显示加载图标；已完成阶段保留勾选，未完成阶段显示失败或已停止。多个并行阶段同时中断时，不猜测具体哪个阶段失败。
- 连接测试成功后，按钮显示绿点「已连接」。修改 URL、模型或密钥会清除成功状态，旧请求返回的结果不会覆盖新配置。保存按钮使用明确的「保存设置」文字。
- 「原文校验」只核对补标点前后的非标点、非空白字符及顺序，不做事实核查。检测到改字会重试，仍不符则沿用对应原字幕，完整内容不会被摘要替代。阅读页可展开说明。

## 视频预览与语音识别

输入完整链接后自动展示封面、标题与作者；预览失败不阻止生成。设置中的「无字幕时转写」默认关闭，开启后使用独立配置的百炼 Paraformer，仅下载纯音轨。密钥可单独配置，也可显式选择「使用自定义 API 密钥」；测试始终使用本页当前填写的对应密钥，无需先保存，空值不回退读取旧密钥。页面保留上传和费用短提示，问号内说明临时音频远端保留约 48 小时、仅用于个人测试，以及使用官方约 4 秒样本的收费测试。转写缓存与重试说明见 [preview-and-asr.md](../docs/preview-and-asr.md)。

「检查来源」须明确点击，独立于标题/封面预览；检查会读取和校验公开字幕及必要的来源信息，不调用 AI、ASR 或下载音频。结果区分公开字幕可读、缺少字幕、已确认的音源限制和仍未确认。网络、权限、格式或身份异常不能被当成“可用”或触发收费转写。已确认的受保护/不支持音源提供查看来源、导入字幕和重新检查；无字幕且 ASR 关闭时，生成按钮转为设置入口，仍由用户自行启用。结果按精确来源在会话中保留最多 32 条、10 分钟，重查期间保留原限制，直到新结果替换；旧链接响应不能影响当前输入。

### 阅读页的关闭层级

Escape 每次只处理最上层。应用对话框、阅读器菜单、导图全屏、Aa / 搜索 / 窄屏目录关闭时各自恢复焦点。关闭阅读页时会先保存位置，再回到进入阅读前的页面。原生工具栏获得焦点时也先询问嵌入阅读页，超时或过期 iframe 响应不会擅自离开文章。输入法组合输入和长按 Escape 不连续退出多层。

### Apple Podcasts

- 首页支持 Apple Podcasts 单集分享链接（含 `i=`），可带节目中文名称和跟踪参数；整档节目页会提示复制单集链接。
- 预览直接读取单集公开页面，显示标题、节目名、时长和封面；同链接请求合并并缓存，等待较久时显示提示与重试，预览失败仍可生成。预览、任务和书架使用紧凑的 1:1 播客封面；最近文章在统一的紧凑媒体区内完整显示方形封面，缺图时保留标题文字封面。
- 先精确定位节目 RSS 的同一单集，优先读带时间戳字幕；确实没有可读取字幕时才使用已启用的 ASR。沿用默认 5 分钟分片、最多 2 片并发、任务恢复和缓存，不需安装额外播客下载工具。
- 对于有效 RSS 只剩频道信息、没有任何单集条目的旧节目，若当前 Apple 页面已核验准确单集及其免费公开音源，可按已开启的 ASR 设置继续；处理记录会说明 RSS 当前未列出单集。网络、权限、RSS 格式或单集身份冲突不使用此兼容路径。
- 网络、权限、字幕格式错误不触发收费转写。不会登录 Apple、读取账号凭据或下载订阅内容。
- 生成、队列、去重、书架、重新整理和 HTML / Markdown 导出与已有来源共用。相同节目/单集编号不会因地区或跟踪参数不同而重复归档。

## macOS 启动排错

- `zsh: command not found: python`：不要依赖系统 `python` 别名。回到仓库根目录，使用 `.venv/bin/python -m pip install -e '.[youtube,test]'`；没有 `.venv` 时先用 Python 3.11+ 的 `python3 -m venv .venv` 创建。无需激活也能使用这个解释器。
- ASR 组件使用 `AsrSettingsPanel.tsx`，配置模块使用 `asrSettings.ts`。扩展名省略时，macOS 的大小写不敏感解析可能将同名 `.tsx` 错认成 `.ts`，因此禁止仅靠大小写区分模块名。
- Vite 只扫描 `desktop/index.html`，不扫描 `src-tauri/target`、嵌入阅读模板或 `build/sidecar` 生成的 HTML。更新后停止旧开发进程，在仓库根目录重新运行 `npm ci --prefix desktop` 和 `sh desktop/dev.sh`。
- 本次修复已在 Linux 和 macOS 上验证前端构建及 Vite 启动；新增模块名冲突检查，避免仅在大小写敏感环境中漏检。原生 Rust 测试不替代前端测试。

## 本地字幕与旧文章升级

- 导入 SRT / VTT / 字幕 JSON 后点击「生成文章」，默认调用当前设置的 Codex、Claude Code 或自定义 API，不再跳过 AI 直接拼接原文。原始文件保持只读；字幕内容将交给所选模型服务处理。
- 未配置 AI 时，本地文件也会提示检查设置，而不是产生看似完成的简陋阅读页。界面在文件下方标明使用哪个 AI 工具。
- 已有文章的 `…` 菜单提供「AI 整理文章 / 重新整理」，复用归档里的 transcript.json 并加入串行队列。处理在后台进行，成功后替换归档，失败保留旧版。当前阅读页通过 Open updated article 由用户主动切换到新版。
- 旧版仅排版原文的文章显示「仅原文」状态，阅读页提供整理入口；不会伪造不存在的摘要、导图或章节。
- 没有封面或者封面加载失败时，使用标题摘取的文字与稳定配色生成排版封面；本地字幕使用 Captions 图标。不会额外调用图片生成服务。
- 已有归档的阅读、缓存重建和导出由应用自带后端离线完成，不需要模型或安装免费的 CLI。

## 分享链接、生成速度与长音频分片

- 直接粘贴 B 站分享标题加链接，或稍后再看页的 `bvid` 链接；粘贴时自动整理为标准视频地址。预览、查重、字幕提取和 ASR 保持同一视频标识，跟踪参数移除、分 P 保留。
- 默认提前并行执行提炼与正文校对，总体并发最多 4 个模型请求；通过校验的批次可在失败后复用，生成归档内 `.performance.json` 可查看实际阶段耗时。更多说明见 `../docs/generation-performance.md`。
- ASR 高级设置默认按 5 分钟分片，提供 10 / 15 分钟和整段转写。长音频分片需要本机 FFmpeg；开启「无字幕时转写」后检查本地版本，就绪时只显示折叠状态，缺失或异常时展开解决入口。可用「选择 FFmpeg…」定位已解压的可执行程序，无需 Homebrew。未安装时可打开 FFmpeg 官方下载页，选择适合 macOS 的版本；App 不自动下载或执行安装脚本。版本检查仅在本地运行、限时 5 秒，与会产生费用的「测试转写」分开。所选路径随设置保存，重启后继续使用，也可恢复自动查找。最多同时转写 2 片，每片独立保存结果和任务 ID，失败后不会重跑成功片段。
- 分片前仍需下载完整纯音轨，不会下载视频画面；不是流式边下载边识别，也不承诺降低按时长计费的 ASR 费用。

## 阅读细节修正

- 阅读正文保持顶部对齐，不再因最大化或摘要、思维导图等 Tab 内容高度变化而垂直居中。App 对旧归档直接应用布局修复，无需重新调用 AI；新生成的独立 HTML 同样修复。
- 主任务卡仅保留当前步骤与一行处理文案，去掉「同时：整理摘要与导图」。展开详情仍可查看实际并行阶段和日志。
- 金句不固定为 6 条，也不固定为 8 条：根据素材质量可多可少，无合适选段时不凑数，仍严格校验原文索引、内容与不重叠引用。已有文章的金句不自动重写，可在 `… → 重新整理` 使用新规则。
- 双击顶部标题栏空白或 LinkRead 品牌区会最大化，再次双击还原；单击拖动保留。设置按钮和文章正文的双击不会缩放窗口。这里的最大化不是 macOS 全屏模式。
- B 站返回 HTTP 图片地址时，只将允许的图片 CDN 地址转换成 HTTPS；提取进度不再用空封面覆盖链接预览。旧归档缺封面时，仅在卡片可见时获取轻量元数据，仍失败就保留文字封面，不必重新生成文章。

## 阅读状态与来源说明

- 首页最近文章和书架使用「…」切换已读及收藏。书架在标题旁显示已读和收藏标记，可组合使用「全部／未读／已读」和「收藏」筛选，返回书架保留筛选条件。Reader 使用 Mark Complete / Mark Unread 和星标按钮。默认未读、未收藏，打开文章不自动标记完成。
- 状态独立保存到每篇归档的 `.reading-state.json`，不改写字幕和 AI 内容。原子写入、跨进程锁与按文章串行更新防止丢失；重新整理或中断恢复保留手动标记，删除文章同时删除其本地标记。
- 旧文章打开时使用原始 JSON 和已有分析离线生成当前界面的 `.reader.html` 缓存；不重新调用 AI，不覆盖原 `article.html` 或字幕。浏览器打开与 HTML 导出使用当前阅读版本。
- 新视频/播客自动保存元数据中的原始 Shownotes。旧文章缺失时，在 Shownotes 点击 Fetch shownotes 显式加载，只取准确原单集的公开简介，不下载音频、字幕，不转写。结果写入独立 `.source-metadata.json`；失败、空结果、超限或错误单集都保留已有数据。
- Shownotes 内网页链接通过系统浏览器打开，只有 HTTP / HTTPS；内容中的脚本、事件、嵌入媒体不会执行。普通书架读取和打开文章保持离线。
- 独立 HTML 的阅读标记使用浏览器本地存储，与 App 后续修改相互独立。原 Notes 标签不再显示，已保存的旧浏览器笔记数据保持原样。

## 生成期间阅读与恢复

- 字幕完整保存后，任务卡出现「先读原文」。预览来自独立的原文快照，不进入正式书架，也不标记为 AI 完成；失败或取消后仍可读取。AI 完成时显示提示，点击 `View finished article` 才切换，当前原文不会被自动替换。
- 原文快照绑定同一单集或原本地文件。移动、删除原文件后仍可从已保存快照继续；同一路径的文件内容已改变时拒绝混用，需重新导入。没有快照的任务恢复后仍要重新检查原来源。
- 「重试未完成部分」复用同一来源、模型、服务地址、提示词和结构约束下校验通过的结果；缓存损坏或配置改变时重新处理。已提交的 ASR 云任务继续沿用原任务 ID 恢复规则，不因重启重复提交。
- 进度详情分别展示模型正在响应、等待并发空位和本地校验的实际数量；最多 4 个模型请求同时运行。最后一次模型结果的时间与普通进度消息分开记录，动画和等待时间不增加完成比例。
- 错误按实际类型提供重试、检查模型设置、检查运行环境、查看来源或详情。失败、取消、中断后所有运行图标停止；只把后端明确报告的阶段标成失败，其余未结束阶段显示已停止。
- Apple 单集即使免费可听，也可能只提供受保护的流式音源。这类任务显示「暂不支持此音源」，保留「查看来源」并移除无效重试；可以导入已有字幕。普通公开文件音源若由准确页面明确确认没有 RSS 和字幕，仍可使用已开启的语音识别；网络错误与未知字幕状态不会触发转写。
- 任务记录在启动处理前完成持久化，写入失败时不开始新任务。读取失败时保留原文件并提供重试，不用空队列覆盖。任务记录和阅读位置采用有上限的白名单格式、私有文件权限及原子写入。

## 继续上次阅读

- 每个来源分别记录活动 Tab 及各 Tab 的位置，思维导图还记录折叠分支和视野。App 保存到私有本地状态；独立 HTML 使用当前浏览器本地存储。阅读位置独立于手动完成和收藏，不会自动标记已读。
- 阅读结束可回到进入时的页面并恢复滚动位置。在阅读器切换主题时，内容和桌面工具栏同步切换。
- 原文切换到完整文章时按字幕锚点恢复，段落重新合并、补标点或调整窗口大小也可接着读。内容确实变化时只恢复能匹配的文本锚点，不能匹配就回到顶部，不按旧像素或全页比例猜位置。
- 恢复后短暂显示 `Resumed reading`，可选择 `Start from top`；只重置当前 Tab。明确打开章节链接、Shownotes 链接或点击导图重置操作时，以当前操作为准。迟到的读取结果不会把正在阅读的页面拉回旧位置。

## 按需工具与原文跳转

- Tab 旁的 Search / Aa 按需展开。⌘F / Ctrl+F 从任意 Tab 查找 Transcript 和 Shownotes，显示当前匹配序号及来源；Enter / Shift+Enter 切换匹配，Escape 关闭。查找完全在本地执行，不请求模型；匹配跨加粗或链接的文字，也不修改原文内容。
- Aa 调整字号、行宽（Standard / Wide）和行距（Compact / Relaxed），保存跨文章的阅读偏好；仅影响 Transcript / Shownotes。调整排版或打开工具时继续保持阅读锚点。Print transcript / Save PDF 放在 Export 菜单中，明确打印正文，再打开系统打印对话框。
- Summary 的章节行直接定位原文章章节；Shownotes 中合法、处于时长范围且有字幕可定位的时间码跳到 Transcript，不创建未经平台支持的播放 URL。原简介中的外部链接保持原地址。
- Keywords 按已保存的关键词顺序排成词云。悬停或键盘聚焦可高亮，点击在 Transcript 和 Shownotes 中查找该词。词云遵循系统「减少动态效果」设置。
- 新生成导图中具有明确来源索引的节点可选择 Read section；节点圆点继续只负责展开/折叠。索引保存为 `mindmap-links.json`，绑定导图内容和源字幕，越界、内容变化或没有索引时不显示跳转；旧导图不会通过标题相似或节点顺序猜位置。

## 快速打开与增量缓存

- 任意页面使用 ⌘K / Ctrl+K 或点击标题栏搜索图标，进入「快速打开」。可查标题、作者、分类与来源，方向键选择，Enter 打开，Escape 关闭。默认优先最近打开的文章，可带着搜索词进入书架查看全部结果。
- 文章打开时校验原文、分析、目录、导图、金句、Shownotes、手动状态及阅读模板；内容未变则复用 `.reader.html`。缓存校验失败会从归档重新生成，不覆盖原始 HTML/JSON，不调用 AI。
- `.library-index.json` 只缓存展示元数据，每次刷新仍核对实际归档；新增或变更的文章单独重新解析，删除项自动移出。索引损坏可重建，写入失败仍能显示书架，不引入数据库。
- 离线性能样本为 200 篇、每篇 1,200 条字幕（约 432 KB JSON）：本次环境中，重复列表读取由约 929 ms 降到 10 ms，重复阅读文件准备由约 11 ms 降到 0.5 ms。数字仅衡量 Python 核心，不含进程启动、IPC 和 WebView 渲染，不能等同于整 App 的打开耗时。

## 已有内容的打开、编辑与复用

- 粘贴已归档的来源后，主操作改为「打开文章」；相同来源正在处理时可「查看任务」并定位到对应记录。打开已有文章不要求先配置 AI，也不受来源当前下载限制影响。「重新生成」保留为显式次级操作，成功后才替换旧文章。
- 书架的更多菜单提供「编辑详情」，阅读器对应入口为 Edit details。可修改显示标题和分类，或使用 Reset to original。修改以独立覆盖层保存，不改原始文稿；书架、搜索、阅读和导出使用相同显示信息，重新生成后仍保留人工修改。
- Highlights 的复制菜单增加 Copy with source：将金句、显示标题、已知作者、时间与来源一起复制为纯文本和富文本。YouTube / B 站使用可信时间链接，Apple 播客保留单集链接和文字时间，本地字幕不附带本机路径。原 Copy highlight / Copy context 继续可用。
- Markdown 导出先选择 Readable article 或 Full note，并可独立启用 Include timestamped transcript。默认阅读稿包含已有摘要与阅读正文，默认不重复附带逐句字幕；完整笔记包括实际已保存的分析和来源说明，导出界面列明范围。两种模式均保留已知出处，仅使用现有数据。
- HTML 保持完整离线阅读页；Print transcript / Save PDF 明确输出正文。Markdown 导出内容不承担整个资料库的恢复功能。
